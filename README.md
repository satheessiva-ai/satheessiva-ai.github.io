# Sathees Siva

Personal leadership portfolio, hosted on GitHub Pages.

Built with static HTML, CSS and JavaScript. The site includes locally hosted fonts, project stories, contact links and a one-page leadership profile. No build step, backend or paid runtime services are required.

## Publishing

GitHub Pages publishes the root of the `main` branch. `.nojekyll` disables Jekyll processing.

## Updates

Edit `index.html`, `styles.css` or `script.js`, then commit to `main`. GitHub Pages publishes the changes automatically. Replace `sathees-siva-leadership-profile.pdf` to update the downloadable profile.

## Fonts

Nimbus Sans and P052 from URW Base35. Font license details are in `fonts/LICENSE.txt`.
